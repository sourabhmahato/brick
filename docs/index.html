Accessible

Easy Customization

Override a handful of CSS variables to completely change the theme. Automatic dark mode from system preferences.

Web Components

Dynamic components like tabs, dropdowns, and tooltips are built as lightweight Web Components.

Quick Start

<!-- Include via CDN -->
<link rel="stylesheet" href="https://unpkg.com/@sourabhmahato/brick/brick.min.css">
<script src="https://unpkg.com/@sourabhmahato/brick/brick.min.js" defer></script>

<!-- Or install via npm -->
npm install @sourabhmahato/brick
