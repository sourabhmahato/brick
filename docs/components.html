What is Brick?

Brick is a minimal, semantic-first UI component library with zero dependencies.

How do I use it?

Include the CSS and JS files, then write semantic HTML.

Is it accessible?

Yes! It uses semantic HTML and ARIA attributes. Keyboard navigation works out of the box.
