Customizing

Brick's entire visual theme is controlled by CSS custom properties (variables). Override them on :root to change the look and feel globally.

Colors

All colors use the light-dark() function for automatic light/dark mode support. Override them to set your own palette:

:root {
  /* Core surfaces */
  --background: light-dark(#fff, #0a0a0c);
  --foreground: light-dark(#0a0a0c, #fafafa);
  --card: light-dark(#fff, #18181b);
  --card-foreground: light-dark(#0a0a0c, #fafafa);

  /* Brand colors */
  --primary: light-dark(#8b4513, #fafafa);
  --primary-foreground: light-dark(#fafafa, #18181b);
  --secondary: light-dark(#f4f4f5, #27272a);
  --secondary-foreground: light-dark(#8b4513, #fafafa);

  /* Semantic colors */
  --danger: light-dark(#d32f2f, #f4807b);
  --success: light-dark(#008032, #6cc070);
  --warning: light-dark(#a65b00, #f0a030);

  /* Neutral tones */
  --muted: light-dark(#f4f4f5, #27272a);
  --muted-foreground: light-dark(#71717a, #a1a1aa);
  --faint: light-dark(#fafafa, #1e1e21);
  --accent: light-dark(#f4f4f5, #27272a);

  /* Borders and inputs */
  --border: light-dark(#d4d4d8, #52525b);
  --input: light-dark(#d4d4d8, #52525b);
  --ring: light-dark(#8b4513, #d4d4d8);
}

Example: Blue theme

:root {
  --primary: light-dark(#2563eb, #60a5fa);
  --primary-foreground: light-dark(#fff, #1e293b);
  --secondary-foreground: light-dark(#2563eb, #60a5fa);
  --ring: light-dark(#2563eb, #60a5fa);
}

Try it: Change --primary to any color and everything updates — buttons, links, focus rings, switches, badges, and more.

Typography

:root {
  --font-sans: system-ui, sans-serif;
  --font-mono: ui-monospace, Consolas, monospace;

  /* Fluid type scale */
  --text-1: clamp(1.75rem, 1.5rem + 1.1vw, 2.25rem);  /* h1 */
  --text-2: clamp(1.5rem, 1.3rem + 0.8vw, 1.875rem);   /* h2 */
  --text-3: clamp(1.25rem, 1.1rem + 0.5vw, 1.5rem);    /* h3 */
  --text-4: clamp(1.125rem, 1.05rem + 0.3vw, 1.25rem); /* h4 */
  --text-5: 1.125rem;                                    /* h5 */
  --text-6: 1rem;                                        /* body */
  --text-7: 0.875rem;                                    /* small text */
  --text-8: 0.75rem;                                     /* tiny text */
  --text-regular: var(--text-6);

  /* Font weights */
  --font-normal: 400;
  --font-medium: 500;
  --font-semibold: 600;
  --font-bold: 600;

  --leading-normal: 1.5;
}

Spacing Scale

A consistent spacing scale based on 0.25rem increments:

:root {
  --space-1: 0.25rem;   /*  4px */
  --space-2: 0.5rem;    /*  8px */
  --space-3: 0.75rem;   /* 12px */
  --space-4: 1rem;      /* 16px */
  --space-5: 1.25rem;   /* 20px */
  --space-6: 1.5rem;    /* 24px */
  --space-8: 2rem;      /* 32px */
  --space-10: 2.5rem;   /* 40px */
  --space-12: 3rem;     /* 48px */
  --space-14: 3.5rem;   /* 56px */
  --space-16: 4rem;     /* 64px */
  --space-18: 4.5rem;   /* 72px */
}

Border Radius

:root {
  --radius-small: 0.125rem;   /* 2px — checkboxes, code */
  --radius-medium: 0.375rem;  /* 6px — buttons, inputs, cards */
  --radius-large: 0.75rem;    /* 12px — dialogs, demo boxes */
  --radius-full: 9999px;      /* pill shapes, avatars */
}

Shadows

:root {
  --shadow-small: 0 1px 2px 0 rgb(0 0 0 / 0.05);
  --shadow-medium: 0 1px 3px 0 rgb(0 0 0 / 0.1),
                   0 1px 2px -1px rgb(0 0 0 / 0.1);
  --shadow-large: 0 4px 6px -1px rgb(0 0 0 / 0.1),
                  0 2px 4px -2px rgb(0 0 0 / 0.1);
}

Transitions

:root {
  --transition-fast: 120ms cubic-bezier(0.4, 0, 0.2, 1);
  --transition: 200ms cubic-bezier(0.4, 0, 0.2, 1);
}

Full Custom Theme Example

Here's a complete custom theme override with a blue palette and rounded corners:

:root {
  /* Blue brand */
  --primary: light-dark(#1d4ed8, #93c5fd);
  --primary-foreground: light-dark(#fff, #1e3a5f);
  --secondary-foreground: light-dark(#1d4ed8, #93c5fd);
  --ring: light-dark(#1d4ed8, #93c5fd);

  /* Rounder corners */
  --radius-small: 0.25rem;
  --radius-medium: 0.5rem;
  --radius-large: 1rem;

  /* Custom font */
  --font-sans: 'Inter', system-ui, sans-serif;
}

/* Or force dark mode */
:root {
  color-scheme: dark;
}
